# 实时调参说明

核对日期：2026-10-22，基于当前工作区。
电机命令已统一为 mm/s；application 不再下发 PWM 计数或选择电机电气方向。

## 操作与保存

进入 Debug tune，顶部 Start/Stop 可在不离开该页的情况下启停；
参数行用 KEY3 编辑，KEY1 增加、KEY2 减少，KEY3 或 KEY4 退出编辑。
编辑中的 KEY4 只退出，再按一次才发布停车。参数在下个约 10 ms 控制周期生效。
Debug tune 顶部提供 Start/Stop，选择后按 KEY3 可在本页启停试车，沿用原启动条件。
Restore defaults 需二次确认，第一次确认只显示 `Reset? 3=OK 4=No`，返回可取消；
正常退出调参页及 Stop/Start 都不会清除已修改的参数。
Control 按相同顺序显示十四项 RAM 参数和 Stage，使用同一份读取和格式化代码。
停止和重新起步保留参数；复位、掉电、Restore defaults 恢复编译时默认值。

## 模块边界

```text
application/race：决定基础速度命令、转向目标、降速和停车状态
application/chassis：根据平滑逻辑转向分配左右轮速度、共同限幅
                     调用 Motor_SetSpeedLR / Motor_Brake / Servo_SetValue
modules/motor：mm/s 换算、最大驱动量限制、死区与左右轮极性
modules/tb6612：方向引脚和 PWM 寄存器操作
```

Motor_Init 负责先停止电机、启动 PWM 定时器及初始化已有测速入口。
调用者无需另行初始化 TB6612。左右轮方向常量属于 motor.h。
当前仍沿用旧工程的开环速度换算，差速属于转向前馈辅助，没有轮速闭环。
Speed mm/s 显示 Race 提供给底盘的基础速度，不是任一车轮命令或实测车速。
未发生饱和时它等于两轮命令均值；外轮饱和、两轮共同缩放后，均值会低于它。

当前默认值保留用户设置的 1200/700/300 mm/s，按现有模块映射约为
5617/3276/1404 PWM。可靠循迹时上坡比例大于 1 会提高驱动量。
实际车速仍需实测，映射由 motor 内的电机和轮子配置决定。

## 控制与限幅

速度目标依次处理：

1. 从 Drive speed 开始。
2. 目标或输出的转向幅度达到 Turn thresh 时，与 Turn speed 取小。
3. 第四阶段根据上坡/坡顶/下坡乘各自比例，平路乘 1；上限为模块最大速度。
4. 几何不可用或有效观测年龄达到 50 ms 时，限制到 Degr speed × min(比例, 1)。
   上坡补偿不放大降级上限，坡顶和下坡继续降低降级目标。IMU 未就绪不允许行驶。
5. 终点停车目标设为 0，按减速率下降；手动或故障停止立即制动。

加速率为 427 mm/s²，减速率为 2136 mm/s²；起步到 1200 约需 2.81 秒。
正常终点停车从 1200 降到 0 约需 0.56 秒；命令为 0 不等于已测得车轮静止。

| 路况 | 直行目标 mm/s | 转弯目标 mm/s | 视觉降级目标上限 mm/s |
|---|---:|---:|---:|
| 平路 | 1200 | 700 | 300 |
| 上坡 | 1500 | 875 | 300 |
| 坡顶 | 960 | 560 | 240 |
| 下坡 | 780 | 455 | 195 |

表中是差速分配前的基础目标，速度命令仍按加减速率跟随，不会因坡道切换瞬间跳变。
当前坡顶判定在恢复水平后短暂存在，约一个确认窗口（100 ms），
可能尚未降到坡顶目标就进入平路；本次沿用原有状态判定。
转弯档不会覆盖更低的直道命令。Drive speed 调到 0 后输出逐步降零，
比赛仍处于启用状态；需要保持停车锁定时使用停止键。

```text
目标转向 = clamp(KP × dev + KH × k, -Limit, +Limit)
允许变化 = Steer slew × dt
输出转向 += clamp(目标转向 - 输出转向, -允许变化, +允许变化)
```

转向 dt 最多取两个控制周期，当前为 20 ms。
Steer slew=700 时，每 10 ms 最多变化 7，中位到 80 约 120 ms，
从 +80 到 -80 约 230 ms；0 为直通。这是命令跟随时间，不是舵机机械转动时间。
Turn target 显示目标，Turn out 显示下发命令，两者以右转为正。

明确丢线、质量不足或观测变旧时保持当前输出，不继续追赶旧目标。
100 ms 超时停车，目标和输出同时清零；重启从中位开始。
调小 Limit 立即限幅，优先于平滑。转向降速同时考虑目标和输出。
当前舵机方向为 +1，中位为 0；底层控制值 -100～100 映射到 1000～2000 μs。
Limit=80 对应 1100～1900 μs，不是左右各 80 度。

建议保持 Degr speed <= Turn speed <= Drive speed，
以及 0 < Turn thresh <= Limit；阈值高于 Limit 时不会触发转弯降速。
KH 是独立航向反馈，不是对 dev 求时间微分，当前没有循迹积分项。

## 差速辅助与最终轮速

差速依据 Turn out，即平滑后的逻辑右转命令，不使用原始 dev、Turn target、
舵机电气方向或道路类型。第三、四阶段启用驱动时生效。
这是一套按转向幅度调节的经验比例，没有使用轴距、轮距或实际前轮转角做几何解算。

```text
u = Turn out
v = 经过降速、坡道与加减速处理后的基础速度
a = clamp((abs(u) - Diff start) / (Limit - Diff start), 0, 1)
r = Diff ratio × a
d = v × r × sign(u)
left = v + d
right = v - d
```

Diff start >= Limit 时辅助关闭，不计算上述除法；Diff ratio=0 也关闭。
默认 |u| <= 5 时同速，在 5～80 间连续增大，达到 80 时满介入。
右转时左快右慢，左转相反。差速比例最大为 0.50，内轮命令不会变成倒转。
当前比例无需累计状态，正常输入变化沿用 Turn out 的平滑；运行中直接改参数会立即生效。

| 基础速度 mm/s | Turn out | 左轮命令 mm/s | 右轮命令 mm/s |
|---:|---:|---:|---:|
| 800 | 5 | 800 | 800 |
| 800 | 42.5 | 960 | 640 |
| 800 | 80 | 1120 | 480 |
| 800 | -80 | 480 | 1120 |

上述数值采用默认 Limit=80、Diff start=5、Diff ratio=0.40。
外轮将超过 MOTOR_MAX_SPEED_MM_S 时，左右轮同时乘同一个缩小比例，
保留两轮命令比值；motor 内部继续执行最终限幅、方向与死区处理。
基础速度接近满输出时，外轮可提升的余量减少，差速主要通过减慢内轮实现。

Degr speed 限制基础速度，差速仍围绕它分配；例如平路降级基础目标 300，
满介入时对应外轮 420、内轮 180 mm/s，并不表示单轮上限为 300。
丢线后冻结的 Turn out 对应同一比例，基础命令按原有降级和超时逻辑处理；
参数不变时不会因继续追赶旧目标而加强差速比例。100 ms 超时两轮制动。
零基础速度、NaN/Inf 或未启用时直接制动，不会因残留转向产生单轮驱动。

当前默认 0.40；需要比较原效果时设为 0。增强比例前先确认转向命令方向正确，
因为差速会同时加强正确纠偏和错误反打。实际轮速差仍需实车验证。

## 验证记录

主机分别验证 application 的模块调用门控和真实 motor 的速度换算、极性、
初始化启动、限幅、零速制动及无效命令制动。
控制回归包括变化率、超时、停车、菜单实时更新及速度上限。
差速回归覆盖左右方向、阈值附近连续性、平滑反号、运行时修改与关闭、
共同限幅、低速不反转、Limit 与阈值退化组合、丢线降级和超时制动。
坡道回归验证倒装 IMU 的上坡加速、坡顶减速、下坡独立比例及平路恢复，
并覆盖三项比例上下限、运行时修改、模块速度钳位及视觉降级不被上坡补偿放大。
硬件实际速度和急弯效果需实车确认；当前参数不代表闭环标定结果。
