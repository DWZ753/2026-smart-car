# 软件回归测试

安装主机 GCC 后，在工程根目录执行：

```text
python tools/run_software_tests.py
```

测试编译实际 PID、Protocol、UART、I2C、SPI 源码，使用模拟外设接口，
不连接硬件。启用优化、编译警告和栈保护，产物写入忽略目录
`Debug/software_tests/`。断言失败或等待无法退出时返回非零状态。

覆盖范围：

- PID 增量累加、微分响应、积分/输出限幅与复位。
- 协议0至64字节载荷往返、非法发送、坏帧、超长帧丢弃与恢复。
- UART 行长度边界、超长行恢复、格式化截断和 DMA/FIFO 超时。
- I2C 等待空闲/完成超时及恢复，SPI TX/RX/忙等待超时。

这些测试验证软件控制路径；真实引脚、外设时序及轮询超时的实际时长
仍需上板验证。
